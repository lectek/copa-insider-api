Como conectar a loja ao Mercado Pago

Esta pagina existe para facilitar a configuracao tecnica do app Mercado Pago. Credenciais continuam sendo preenchidas somente no painel admin.

Entrar no assistente admin Voltar para a loja

1. Antes de tudo

  1. A conta bancaria que recebe os repasses e configurada no proprio Mercado Pago.
  2. No sistema da farmacia, o admin conecta a conta Mercado Pago por OAuth.
  3. As URLs abaixo sao as que precisam ser cadastradas no app do Mercado Pago.

2. URLs prontas para copiar

3. O que preencher no Mercado Pago

  1. Crie ou abra o aplicativo da loja no painel de desenvolvedores do Mercado Pago.
  2. Cadastre a `Redirect URI` exatamente como mostrada nesta pagina.
  3. Se usar notificacao manual no app, confira tambem a `Webhook URL`.
  4. Copie `Client ID` e `Client Secret` e leve esses valores para o assistente admin.

4. O que preencher no admin

  1. Entre no assistente admin do Mercado Pago.
  2. Preencha `Client ID`, `Client Secret`, `Redirect URI` e o `owner reference` da loja.
  3. Clique em `Salvar e conectar agora`.
  4. Ao voltar do Mercado Pago, rode o `Testar checkout` e finalize um pagamento real de teste.

5. Quando considerar pronto

A integracao deve ser considerada pronta somente quando o admin confirmar os quatro itens abaixo no assistente:

  • Credenciais OAuth configuradas
  • Conta conectada
  • Checkout testado
  • Webhook real confirmado
