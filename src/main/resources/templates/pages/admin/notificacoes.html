Notificacoes

Envie avisos para usuarios do aplicativo.

Disparo rapido

Use a API para enviar notificacoes para usuarios ou todos.

POST /admin/notificacoes/api/enviar (lista de usuarios)
POST /admin/notificacoes/api/enviar/todos (broadcast)
POST /admin/notificacoes/api/enviar/usuario/{id}
POST /admin/notificacoes/api/enviar/estoque-baixo

Payload: tipo, titulo, mensagem.
