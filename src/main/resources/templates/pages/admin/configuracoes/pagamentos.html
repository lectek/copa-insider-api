Checklist de homologacao

Siga este roteiro ate o badge de webhook real ficar confirmado.

  1. OK Pendente Configure `Client ID`, `Client Secret` e `Redirect URI` do app Mercado Pago.
  2. OK Pendente Selecione `Mercado Pago` como gateway ativo.
  3. OK Pendente Conecte a conta da loja usando o `owner reference` correto.
  4. OK Pendente Garanta uma URL publica em HTTPS para o webhook.
    Webhook efetivo: https://api.exemplo.com/webhooks/mercadopago
    O sistema ainda nao conseguiu montar uma URL de webhook. Revise `pg.webhook_url` ou a `app.web.base-url` em HTTPS.
  5. OK Pendente Rode o botao `Testar checkout` em uma conta conectada e abra a URL gerada.
  6. OK Pendente Conclua um pagamento de teste e volte para confirmar o recebimento do webhook real.
