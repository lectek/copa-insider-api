1. Copie as URLs prontas

Use estes valores no app do Mercado Pago. A conta bancaria continua sendo configurada dentro do proprio Mercado Pago.

2. Salve as credenciais

Este formulario guarda apenas o necessario para o OAuth e ja força o gateway ativo para Mercado Pago.

Se voce deixar em branco, o assistente usa a URL pronta acima.

3. Teste a conexao

Depois da autorizacao, rode um smoke test para gerar uma preferencia real e abrir o checkout do Mercado Pago.

5. FAQ rapido

  1. A conta bancaria para receber os valores e configurada dentro do Mercado Pago, nao aqui na API.
  2. Se o webhook estiver vazio, configure `APP_WEB_BASE_URL` em HTTPS ou preencha um webhook manual.
  3. Se houver mais de uma loja, mantenha um `owner reference` por conta e use o mapa `tenant -> owner reference`.
  4. Depois do primeiro pagamento real de teste, este assistente passa a mostrar o webhook como confirmado.
